# Requirements

## Functional requirements (what the system must DO)

1. FR1: The system shall allow users to upload a facial image for skin condition analysis.
2. FR2: The system shall classify the user's facial skin condition based on the uploaded image.
3. FR3: The system shall allow users to upload an image of a skincare product's ingredient list.
4. FR4: The system shall extract ingredient information from the uploaded image using Optical Character Recognition (OCR).
5. FR5: The system shall assess ingredient compatibility based on the user's skin profile and personal sensitivities, and display the results with explanations.

## Non-functional requirements (how the system must PERFORM)

1. NFR1: The system shall display skin analysis and ingredient assessment results within 10 seconds after processing is complete.
2. NFR2: The system shall protect users' personal information and uploaded images from unauthorized access.
3. NFR3: The system shall provide a user-friendly interface that allows users to upload images and understand assessment results easily.
