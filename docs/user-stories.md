# User Stories

1. As a skincare user, I want to upload a facial image for skin condition analysis, so that I can understand my facial skin profile. (FR1, FR2)

   Acceptance criteria:
   - I can upload a facial image in a supported image format.
   - The system displays the detected skin condition after analysing the uploaded image.

2. As a skincare user, I want to upload an image of my skincare product's ingredient list, so that I can identify the ingredients in my existing product. (FR3, FR4)

   Acceptance criteria:
   - I can upload an image containing the product's ingredient list.
   - The system extracts and displays the ingredient text detected from the uploaded image.

3. As a skincare user, I want to assess the compatibility of my existing skincare product with my skin profile and personal sensitivities, so that I can make informed decisions about using the product. (FR5)

   Acceptance criteria:
   - The system displays a compatibility assessment based on my skin profile, personal sensitivities, and the extracted ingredients.
   - The system explains which ingredients may be suitable, require caution, or present potential concerns.
